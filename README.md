# FarZoom

Необходимо реализовать одностраничное приложение в виде SPA.

## Установка

```bash
git clone git@github.com:vedmond/far-zoom-spa.git
```

Для установки зависимостей выполните:

```bash
npm install
```

## Запуск

Для запуска приложения локально:

```bash
npm run start
```

Для сборки:

```bash
npm run build
```

Для получения данных использован сервис [mockapi.io](https://mockapi.io/).

Время потраченное на выполнение задания около семи часов
